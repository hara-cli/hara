# Authenticated command receipt lookup

`workspace.boundaries.control.lookup` accepts only workspaceId, expectedGeneration, agentId and commandId. It uses the actual C1 owner connection and the same manage-or-invoke reader rule as receipt. Discovery capability `workspace.agent-command-receipt-lookup.v1` is advertised only alongside explicitly enabled command control; an advertisement is not authentication. Default CLI/native/production admission remains disabled.

The private projection is `{schemaVersion:1, kind:"command-receipt-lookup", context, agentId, commandId, observedAt, state, receipt}`. `seen` carries the original C0 v1 receipt. `not_seen` carries null only after healthy hot/retired lookup and full lifecycle history verification. Errors, missing/corrupt history, wrong generation/reader/agent or unhealthy authority never become absence. Original readReceipt semantics and C0 v1/types/fixtures/error codes remain unchanged.

observedAt uses the authority clock that enforces command deadlines and is sampled BEFORE reading the snapshot. A reader must not treat a pre-expiry observation as proof after a slow response. A pre-existing intake is still checked against notAfter inside the real CAS. Desktop keeps the original validated draft's issuedAt/notAfter in a version2 minimal local reference and retires only the exact reference after a bound not_seen observation exceeds notAfter+1000ms. Client clock/age/error is insufficient; missing endpoint and legacy references without deadlines stay held. Accepted/UNKNOWN/effect observations are never retired by expiry. This lookup performs no command admission, ledger write, effect, model call or automatic retry.

The observation holds the very same private Workspace JSON lock as CAS publication. It is read-only (no state/revision write). A writer that already validated just before expiry must finish publishing before absence can be observed; a writer acquiring the lock afterwards rechecks notAfter. Lock contention or IO returns an authority error, never not_seen or a Host-wide corruption flag. The authority clock is sampled inside this lock before the validated hot/history snapshot.
